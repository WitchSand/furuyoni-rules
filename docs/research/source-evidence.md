# 术语来源证据记录

访问日期：2026-08-04

本文件只记录 `PLAN.md` 允许的证据体系。日文 PDF 决定规则语义；网络来源只用于判断简中推荐名、社区别名和冲突。任何单一旧民译均不作为权威。

## 证据等级

| 等级 | 使用边界 |
| ---: | --- |
| 1 | 获原作方认证与监修项目中的简中用语 |
| 2 | 受原作方协助运营、但中文明确未经监修的半官方模拟器 |
| 3 | 至少两个独立简中社区来源形成的共识 |
| 4 | 旧版综合规则民译，仅用于差异核对 |
| fallback | 无充分简中依据时采用直译或音译，并标为 provisional |
